# 服务器安装与升级资产

`deploy/server/` 用于归档本地服务器安装、升级、回滚和运行时目录初始化相关资产。当前阶段只声明归档边界，不迁移现有文件。

## 资产范围

适合归入本目录的资产包括：

- 生产服务器安装入口。
- 运行时目录和数据目录初始化模板。
- `.env`、`.config.yaml` 等部署配置模板。
- 升级、回滚、备份和恢复入口。
- 面向服务器的 systemd、日志轮转、权限初始化等运行配置。

## 当前保留位置

以下服务器部署相关资产暂时保留在现有位置：

- `scripts/install-private-docker.sh`
- `main/xiaozhi-server/docker-compose_all.yml`

这些资产已经被生产部署流程引用。后续迁移时，原路径必须继续可用一段兼容期，可以通过轻量包装脚本转发到 `deploy/server/` 下的新入口。

## 与 docs/deployment 的边界

`docs/deployment/` 描述安装、升级和排障步骤；`deploy/server/` 保存这些步骤实际调用的安装资产。文档中出现的命令应优先引用稳定入口，而不是散落的内部文件。

## 与 scripts 的边界

如果脚本只服务本地开发、检查或一次性维护，应保留在 `scripts/`。如果脚本是生产服务器安装或升级的正式入口，后续应迁入或映射到 `deploy/server/`。
